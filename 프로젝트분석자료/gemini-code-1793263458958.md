# [Action-PRD] Vibe Coding 쾌속 빌드를 위한 핵심 요약

## 1. 1차 스프린트 MVP 범위
- [ ] 반응형 단일 랜딩페이지 레이아웃 완성 (GNB + 6개 메인 섹션 + Footer)
- [ ] 직무 목록 탭 필터링 및 상세 보기 바텀시트/모달 구현
- [ ] 지원 기간 D-Day 카운트다운 타이머 구현
- [ ] 반응형 FAQ 아코디언 컴포넌트 완성

## 2. 스타일 가이드 토큰 요약
- **Primary Color**: Deep Blue (`#003876`) - 한미약품 신뢰감
- **Accent Color**: Vivid Cyan/Teal (`#00A3E0`) - 혁신성
- **Neutral Color**: Gray-50 (`#F8FAFC`) ~ Gray-900 (`#0F172A`)
- **Typography**: Pretendard, sans-serif
